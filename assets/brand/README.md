# AccelPro logo system

## Files

- `accelpro-mark.svg` / `.png` — standalone coaching and progress symbol.
- `accelpro-logo.svg` / `.png` — master **AccelPro** logo for all offerings.
- `accelpro-affiliate-academy.svg` / `.png` — horizontal **AccelPro Affiliate Academy** lockup.
- `accelpro-affiliate-academy-stacked.svg` / `.png` — compact stacked lockup.
- `logo-sheet-preview.png` — quick visual reference showing the complete system.

## Reusable naming pattern

Keep the symbol and **AccelPro** wordmark unchanged. For future offerings, replace only `Affiliate` in the descriptor while keeping `Academy` unchanged.

Examples: **AccelPro AI Academy**, **AccelPro Leadership Academy**.

## Colours

- Primary black: `#111111`
- Brand gold: `#C9A227`
- Offering accent: `#5A3A2E`

Use the SVG files wherever possible so the logo stays sharp at every size. Maintain clear space around the logo equal to at least half the symbol width. Do not stretch, rotate, recolour, or rearrange the master symbol and wordmark.
